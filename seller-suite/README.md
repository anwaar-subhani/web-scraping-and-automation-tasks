# Amazon Seller Scraper Suite

This folder contains the modular Amazon seller scraping suite, including the reusable scraper package, Google Sheets support, progress tracking, and sample UI/test files.

## What I did

- Split the scraper into reusable modules.
- Added browser, URL, file, and progress helpers.
- Supported Google Sheets-driven scraping with resumable runs.
- Kept only example credential templates for local setup.

## Main entry point

- `main.py`
- `scraper/` for the reusable package code

## GitHub notes

- Generated output, secrets, and stray sample artifacts are removed or ignored.
- Use the example credential files as templates for local setup.
