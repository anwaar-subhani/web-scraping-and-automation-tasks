# Amazon Seller Scraper

This project scrapes third-party Amazon seller details for a single keyword and market.

## What I did

- Opened Amazon search results for the configured keyword.
- Visited product pages and seller profile pages.
- Extracted the seller business details.
- Saved the results to a local spreadsheet file.

## Main entry point

- `script.py` — Playwright-based scraper.
